この記事は開発サーバーでスクロール深度トラッキング（`scroll_depth` イベント）の動作確認をするためのフィクスチャです。
ページをスクロールすると、ブラウザの開発ツール（コンソール）に `[scroll_depth] event scroll_depth { percent_scrolled: 25 }` のようなログが表示されます。

## スクロール深度トラッキングとは

ページの表示高さの何割までスクロールされたかを計測する機能です。
25%・50%・75%・90%・100% の閾値に到達するたびにイベントが発火します。
各閾値は1ページロードにつき1回のみ発火します。

本番環境では Google Analytics（GA4）にカスタムイベント `scroll_depth`（パラメータ: `percent_scrolled`）として送信されます。
開発サーバーでは gtag の代わりにブラウザコンソールへログを出力します。

## 確認手順

### 開発サーバーでの確認

1. `npm run dev` で開発サーバーを起動する
2. ブラウザでこの記事を開く
3. 開発ツールのコンソールを開く（F12 → Console タブ）
4. ページをゆっくりスクロールする
5. 各閾値（25%・50%・75%・90%・100%）に達するたびにコンソールにログが出ることを確認する

### 本番環境での確認（GA4 DebugView）

GA4 のリアルタイムレポート画面では `scroll_depth` のようなカスタムイベントは「イベント数（イベント名別）」に表示されません。
リアルタイムで確認するには GA4 の **DebugView** 機能を使います。

1. URL に `_ga_debug=1` をクエリパラメータとして付けてページを開く（例: `https://www.nahcnuj.work/essays/...?_ga_debug=1`、すでに他のクエリパラメータがある場合は `&_ga_debug=1`）
2. GA4 管理画面の「管理」→「DebugView」を開く
3. ページをスクロールする
4. DebugView のタイムライン上に `scroll_depth` イベントがリアルタイムで表示されることを確認する
