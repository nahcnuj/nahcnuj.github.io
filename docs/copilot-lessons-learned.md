# Copilot 自己省察：OGP自動生成機能の実装で学んだこと

OGP画像の自動生成機能を実装するまでに 5 つの PR（#579 #583 #585 #587 #589）が必要になりました。
次回以降同じ失敗を繰り返さないために、反省点と注意事項をまとめます。

---

## 1. ワークフローファイルはすべて同期して修正する

**何が起きたか**  
`ci.yml` と `deploy.yml` に `fonts-noto-cjk` のインストール手順を追加した PR #587 のとき、
もう一方の実際のデプロイ経路である `update.yml` への追加が漏れていました（#586/#588/#589）。

**気をつけること**
- 複数のワークフローファイルが存在する場合、同種の手順が必要なジョブがないか **全ファイルを確認** する。
- システムフォントや外部ツールのインストールなど、環境依存の前提条件を変更するときは、
  `ci.yml` / `deploy.yml` / `update.yml` の **3 ファイルを必ず一括で確認・更新** する。

---

## 2. システムフォントなど環境依存の前提条件は統合テストで検証する

**何が起きたか**  
`@resvg/resvg-js` はフォントが見つからないとき CJK グリフを **無音で** 描画しません。
ユニットテストはパスしたが、実際の PNG には日本語が出力されていませんでした（#586/#588）。

**気をつけること**
- 「フォントがなければサイレントに失敗する」ライブラリを使う場合は、
  実際に PNG を生成して **描画結果を検証する統合テスト** を必ず用意する。
- 統合テストはプロジェクトルートの `tests/` ディレクトリに配置する（ユニットテストと分離）。
- テストが「フォントなしでも通過してしまう」状態にならないよう、
  CJK グリフを含む PNG と含まない PNG のバイトサイズを比較するなど、
  **フォントがないと失敗するアサーション** を含める。

---

## 3. 静的タイトル文字列の改行は明示的に `\n` で書く

**何が起きたか**  
`STATIC_TITLES['index']` に `\n` がなく、`wrapLines` が長い英語部分を途中で切断し
「Hayashi)」だけが表示されていました（#584）。

**気をつけること**
- 複数行にわたるタイトルを持つ固定ページ（トップページなど）は、
  `'林 純一\n(Junichi Hayashi)'` のように **明示的に `\n` で改行位置を指定** する。
- `wrapLines` の自動折り返しロジックに全面的に依存しない。
  意図したタイトル表示になっているかを **OGP プレビューや SVG の `<text>` 要素で確認** する。

---

## 4. 修正が実際に本番環境に到達しているか確認する

**何が起きたか**  
バグ修正 PR をマージしても、デプロイワークフローに漏れがあったため
本番の OGP 画像は修正されていませんでした。

**気をつけること**
- PR マージ後は実際にデプロイされた成果物（今回なら OGP PNG の URL）を確認し、
  修正が **本番に反映されていること** を検証する。
- CI が通っても「CI のビルドと本番デプロイは別のワークフロー」であることを常に意識する。

---

## 5. テストの配置ルール

| テストの種類 | 配置場所 |
|---|---|
| ライブラリ・ユーティリティのユニットテスト | `app/lib/*.test.ts` |
| コンポーネントのユニットテスト | `app/lib/*.test.tsx` |
| 複数モジュールをまたぐ統合テスト | `tests/*.test.ts` |
