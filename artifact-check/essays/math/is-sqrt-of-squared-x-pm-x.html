論理和の略記：方程式

x2=4x^2 = 4x2=4 の解は x=+2,−2x = +2, -2x=+2,−2 である。これらを x=±2x = \pm 2x=±2 と省略して書くこともある。これは x=+2∨x=−2x = +2 \lor x = -2x=+2∨x=−2 くらいの意味だろう。+2≠−2+2 \neq -2+2=−2 だから x=+2∧x=−2x = +2 \land x = -2x=+2∧x=−2 は偽だ。

この考え方を冒頭の式に適用すると、次の論理式 (★) の略記といえる。

\sqrt{x^2} = +x \lor \sqrt{x^2} = -x \tag{\star}

この命題は真である。 証明： x≥0x \ge 0x≥0 のとき、 x2=+x\sqrt{x^2} = +xx2​=+x だから、(★) は真。x<0x < 0x<0 のとき、 x2=−x\sqrt{x^2} = -xx2​=−x だから、(★) は真。したがって、任意の実数 xxx に対して論理式 (★) は真である。（証明終）

このように考えるなら、冒頭の式は正しいと言えそうだ。

復号同順：恒等式

「±」という記号は、以下のように「復号同順」という言葉と共に使われることもある。

(x±y)2=x2±2xy+y2（復号同順）(x \pm y)^2 = x^2 \pm 2xy + y^2 \quad \text{（復号同順）}(x±y)2=x2±2xy+y2（復号同順）

これは復号がある復号の同じ側を取ることにして、以下の2つの恒等式をまとめて書いたものである。

{(x+y)2=x2+2xy+y2(x−y)2=x2−2xy+y2\begin{cases} (x + y)^2 = x^2 + 2xy + y^2 \\ (x - y)^2 = x^2 - 2xy + y^2 \end{cases}{(x+y)2=x2+2xy+y2(x−y)2=x2−2xy+y2​

これらはどちらも成り立つ。

一方、冒頭の式には復号がつしか出てこないので無意味かもしれない。「どちらも」真となるか、すなわち次の命題を考える。

\sqrt{x^2} = +x \land \sqrt{x^2} = -x \tag{\diamond}

反例はすぐに挙げられるだろう。(◇) は偽である。例えば x=2x = 2x=2 なら x2=22=4=2≠−2\sqrt{x^2} = \sqrt{2^2} = \sqrt{4} = 2 \neq -2x2​=22​=4​=2=−2 であるから反例となる。

もっとも、冒頭の式には復号がつしか出てこないから、このように考えるのは野暮かもしれない。
