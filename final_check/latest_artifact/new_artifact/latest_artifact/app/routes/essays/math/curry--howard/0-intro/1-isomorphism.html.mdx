# 「同型」とは
「カリー＝ハワード同型対応」の主張を理解するために、差し当たって「同型」とは何かを知る必要がある。
とはいえ、この「同型」という言葉は普通の数学における同型（isomorphism）と一緒である。
したがって、それを既に理解していれば[次の節](./2-statement.html)に進んで構わない。
