# 2026年3月1日
## Resolve conversationの罠
GitHub Copilotにレビューさせると、レビューコメントに「Implement suggestion」のボタンが付く。
このボタンを押すとCopilotに対応するよう返信するコメントの文面が生成され、そのまま送信すればCopilotに指示できる。

私があるレビューコメントに対して対応不要の意図で「Resolve conversation」した後、別のレビューコメントについては対応してほしかったので「Implement suggestion」から対応するように指示した。
するとResolve済みのconversationに対するsuggestionまでimplementationされてしまった。

明示的に対応不要である旨をテキストで残さなければならないのか。
