# 【完全攻略】カリー＝ハワード同型対応
「証明する」ことと「プログラムを書く」ことは、本質的に同じことである。
これが数学的な裏付けを持つことを主張するのが「カリー＝ハワード同型対応」である。
[Rocq（旧Coq）](https://rocq-prover.org/)や[Lean](https://lean-lang.org)はこの関係を利用した証明支援系である。

証明支援系の実用にあたっては、そのような対応関係があることを知っていれば十分であろう。
しかし、実際にカリー＝ハワード同型対応がどのような定理でどのように証明されるのかは非自明なことである。
本シリーズでは、非常に小さな形式体系とプログラミング言語を定義し、証明とプログラムが同型対応を持つことを証明する。

前提知識は数学の「集合」の概念が分かっていれば良い。
特に「論理」には詳しくある必要はない。
それはこれから定義していくものであり、かえって理解を妨げうるからだ。
